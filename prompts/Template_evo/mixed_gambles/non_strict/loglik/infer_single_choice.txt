You are given observations of human choices in mixed-gamble problems.

Each problem presents two options:
- One risky gamble with possible gains and losses
- One certain outcome

Option convention:
- Option A = gamble_A / accept the risky gamble
- Option B = gamble_B / certain option / reject the risky gamble
- action 0 = choose gamble_A
- action 1 = choose gamble_B

All information about outcomes and probabilities is fully described in the problem.
Each decision is independent.

IMPORTANT DATA PROPERTIES:
- has_feedback is always False
- history does NOT contain useful information
- There is NO outcome realization shown to the participant
- Choices depend only on the current gamble, not past trials

IMPORTANT — Evaluation metric:
Mixed gambles are evaluated using log-likelihood.

Your program must return a probability:

    P(action = 1)

where:
- action 0 = choose gamble_A / accept the risky gamble
- action 1 = choose gamble_B / choose the certain option / reject the risky gamble

The goal is to MAXIMIZE log-likelihood.
Higher log-likelihood is better. Since log-likelihood values are usually negative, values closer to 0 are better.

Key implications:
- Return a smooth probability in [0, 1], not only hard labels 0 or 1.
- Higher returned values mean the participant is more likely to choose gamble_B / reject the gamble.
- Lower returned values mean the participant is more likely to choose gamble_A / accept the gamble.
- Avoid returning exactly 0.0 or exactly 1.0, as this can cause very poor log-likelihood when wrong.
- Do not sample or use randomness.

Write Python code that reproduces the observed behavior.

You must generate a complete program implementing:

def choose(problem, history):
    """
    problem: dict with keys
        - gamble_A: {"probs": List[float], "rewards": List[float]}
        - gamble_B: {"probs": List[float], "rewards": List[float]}
        - option_keys
        - has_feedback: bool

    history: unused (may be empty)

    return: float, probability of choosing action 1
            action 1 = gamble_B / certain option / reject the risky gamble
    """

REQUIREMENTS:
- Pure Python.
- Deterministic code only: same inputs should always produce the same probability.
- Use ONLY information from the current problem.
- Do NOT rely on history or feedback.
- Return a single float in [0, 1].
- The returned value must be the probability of choosing action 1.
- Prefer simple, consistent probabilistic decision rules.
- Avoid symmetric rules that treat both options identically.
- Do not sample or use randomness.
- Do not call external APIs.

Output ONLY the complete choose(...) function.
