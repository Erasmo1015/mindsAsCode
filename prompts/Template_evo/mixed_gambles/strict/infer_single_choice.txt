IMPORTANT DATA PROPERTIES:
- has_feedback is always False
- history does NOT contain useful information
- There is NO outcome realization shown
- Choices depend only on the current gamble, not past trials

Write Python code that reproduces the observed behavior by implementing a PARAMETRIZED decision model.

You MUST generate a parametrized persona (a small set of numeric parameters), not a verbal or ad-hoc rule.

Mandatory requirements:
- The code must explicitly define a fixed set of numeric parameters (floats or ints).
- All behavior must be expressed only through these parameters.
- Parameters must appear in a clearly marked section named exactly:
  “Parameters (fixed)”.

Required function:

def choose(problem, history):
    """
    problem: dict with keys
        - gamble_A: {"probs": List[float], "rewards": List[float]}   # risky mixed gamble
        - gamble_B: {"probs": List[float], "rewards": List[float]}   # certain option (often single reward)
        - option_keys
        - has_feedback: bool
    history: unused (may be empty)
    return: int (0 or 1)  # 0 for A, 1 for B
    """

Model guidance (must be parameterized, deterministic):
- Compute a utility for accepting the gamble using a weighted gain–loss form (e.g., G - omega * L).
- Use a logistic / sigmoid decision rule with a consistency parameter (e.g., lambda).

Constraints:
- Pure Python
- Deterministic
- Use ONLY information from the current problem
- Do NOT use history or feedback
- No external libraries/APIs

Output format:
Output ONLY the complete choose(...) function.
