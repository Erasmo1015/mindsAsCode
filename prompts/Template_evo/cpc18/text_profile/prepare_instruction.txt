You are preparing a scoring instruction for evaluating behavioral structure in the CPC18 Track II individual-choice task.

Each problem presents two options: Option A and Option B.

Problem format:
- Ha: high outcome of Option A
- pHa: probability of Ha
- La: low outcome of Option A
- LotShapeA: lottery shape of Option A, one of "-", "Symm", "L-skew", "R-skew"
- LotNumA: number of outcomes for Option A
- Hb: high outcome of Option B
- pHb: probability of Hb
- Lb: low outcome of Option B
- LotShapeB: lottery shape of Option B, one of "-", "Symm", "L-skew", "R-skew"
- LotNumB: number of outcomes for Option B
- Amb: 1 if ambiguous, 0 otherwise
- Corr: correlation, one of -1, 0, or 1

A trial may include history:
- action: 0 for Option A, 1 for Option B
- feedback: numeric value or None

Create a short instruction for scoring participant-level behavioral structure.

The scorer will receive training trials for multiple participants and should output one JSON object mapping participant ids to evidence scores.

The JSON format must be:

{
  "participant_0": {
    "evidence": {
      "evidence_name_1": 0.0,
      "evidence_name_2": 0.0
    },
    "summary": "text"
  },
  "participant_1": {
    "evidence": {
      "evidence_name_1": 0.0,
      "evidence_name_2": 0.0
    },
    "summary": "text"
  }
}

Each evidence value must be a number in [0,1].
Higher evidence values mean stronger evidence of coherent, predictable behavioral structure.
The final structure score will be computed by code as the average of the evidence values.
The scorer should not output the final structure score.

After the JSON format, explain:
- what each evidence score measures
- what low evidence means
- what high evidence means

Return only the scoring instruction text.
Do not output JSON now.
